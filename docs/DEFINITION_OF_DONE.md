# Definition of Done

Uma tarefa relevante somente pode ser considerada concluída quando todos os itens aplicáveis estiverem satisfeitos:

- [ ] Código implementado e revisado.
- [ ] Issue criada antes da implementação.
- [ ] PR vinculada à Issue.
- [ ] Architecture Review realizada quando a mudança afetar arquitetura, segurança, tenancy, concorrência, MongoDB ou integrações.
- [ ] Testes adequados executados; gates condicionais identificados sem simulação de sucesso.
- [ ] CI verde.
- [ ] Segurança e multi-tenancy avaliados.
- [ ] Contratos/API e migrações documentados quando aplicável.
- [ ] Documentação/runbook atualizado quando necessário.
- [ ] Riscos residuais, débitos técnicos e limitações registrados.
- [ ] Plano de rollback definido e verificável.
- [ ] Nenhum segredo ou dado sensível foi adicionado ao repositório.
